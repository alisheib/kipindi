Visual pass round 5 (R5-H): every loading ghost a client reference, not a drawn tree in every refresh; the ghosts' bands the pages' bands; the journey flag and the not-found mark in the first paint they belong to

From the code review's G1/G2 (R5-D's technique, extended) and R5-B's and R5-D's follow-ups G-2, G-2b and G-3.

G-2 · every player loading.tsx was a server component, so Next put its whole drawn tree into every payload that
renders the segment — the document, every move into it, and every router.refresh() (which renders from the root).
Measured per segment (sw): wallet/receipts 9,556 B, results 8,217, positions 5,125 (journey) / 8,065 (classic), wallet
6,826, agent 4,875, markets 4,721 … — 92,274 B over all player segments. One convention now, written once in
src/components/ui/page-loader.tsx: the drawing is client code and reads its own words with useT() (the root layout
gives the provider the language from the kp-locale cookie, the same expression getServerT uses — the server's HTML is
unchanged); a loading file that needs no server answer IS the drawing ("use client"); one that needs an answer stays a
server file and hands the drawing only that answer (the journey answer, `bonusLive`). The journey's pictures ride R5-D's
lazy binding, pinned to the page (`<LazyJourneyRouteGhost rails at="/positions" />`), so no server file imports one.
After: 19–100 B per segment element, 3,298 B over all of them; per refresh /wallet/receipts 16,868 → 541 B (67.5 → 2.2
KB a minute), /markets/[id] 8,579 → 933, /updown/[roundId] while awaiting a result 3,793 → 524 every 5 s. The drawn
markup is byte-identical (react-dom/server, 39 files × 3 languages × 2 shells: 222/234 identical, the other 12 the G-2b
bands below). Admin's 61 loading files (staff-only, English-pinned, never polled) and /s/[token] are left as they are.

announced the change while the shell's mark was still in the DOM — since React 19.2 (as Next ships it) a transition's
passive effects run after the paint, so one painted frame showed the old answer in both directions. The flag is raised
in a layout effect from a bare mount beside the journey header and tabs (the commit that first paints them); lowered at

nodes go). Siblings: the not-found mark's departure; strip-autoscroll's `data-edges` (no faded end on the first frame
after a move). The route entrance (route-transition.tsx) is proposed as a patch and proved in a browser separately.
