From the edge scenarios' Slow-3G and not-found read (M9). Every finding was re-measured from the tiles first.

- E36: on all 16 mid-load tiles the journey header band was one colour (5,2,79) and the rail was missing, while the
  DOM held both.
  - Cause: each journey arm was the only child of its own <Suspense>, and React 19.2's server renderer outlines a
    finished boundary over 500 bytes once the shell passes 12,800. The fallback (an empty .kp-jhdr, or nothing) is
    written in place, and the part waits in a hidden div for the inline $RC script; with scripting off it never
    appears.
  - Fix: both arms render bare in AppShell, journey only. test:visual-pass-r4j §1 proves the outlining on React's own
    server renderer, with a boxed control.
  - What the boundary protected is kept another way:
    - the capsule is drawn masked until the browser's stored choice is read (WalletBalanceCaptioned), with the same
      box widths (D31);
    - the client-mounted bell has a still twin (BellStill, a plain link to /notifications) holding its slot.
  - Cost: a page's hydration now also waits for the two small preloaded chunks.
- E37/E41: 22 of 27 tap frames showed the chrome doubled and dimmed ("TZS 188,888"), and two tabs were lit.
  - Cause: route-transition.tsx started a View Transition of the whole document after the router had committed, so
    both snapshots were of the new page, and the rail's pip froze mid-transition.
  - Fix: a journey reader gets the page wrapper's CSS entrance only (journeyFlagSnapshot), and the journey's rail
    pip and nav underline do not transition. The classic cross-fade is untouched.
  - Tile 328's blank is a CDP capture inside the transition's render suppression; a viewer keeps the last frame.
- E38: every journey loading state was the root SectionLoader box (phones y252–612; at 1280 x32–1247 against the
  x132–1147 column). The root loading now draws JourneyRouteGhost for a journey reader (AppShell's own gates), and
