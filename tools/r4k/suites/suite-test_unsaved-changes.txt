§3 · a draft carries every typed control, and restores into a React-controlled field (vb6)
  PASS 3.1 a draft carries named inputs, textareas and single selects — never a password, a file, a radio, a multi-select or a nameless control
  PASS 3.2 ⭐ a textarea's draft restores INTO A CONTROLLED FIELD — its onChange receives the draft, so the next render keeps it
  PASS 3.3 a select's draft is written and raises `change` — the event React's onChange for a select listens to
  PASS 3.0b the in-memory copy of the draft helpers with NOTHING planted passes 3.1–3.3 — so a red plant below is the plant
  PASS 3.1c CONTROL · a copy whose draft skips the textarea (the pre-fix inputs-only draft) fails 3.1
  PASS 3.2c CONTROL · a copy that restores through the element (`.value =`, the pre-fix restore) leaves the controlled field on its old text — 3.2 refuses it
  PASS 3.3c CONTROL · a copy that never tells a select `change` fails 3.3
  PASS 3.4 useFormDraft writes its draft with draftValuesOf(form.elements) and restores it with restoreDraftInto(form.elements, …)
  PASS 3.4c CONTROL · a hook that no longer restores through restoreDraftInto is reported
