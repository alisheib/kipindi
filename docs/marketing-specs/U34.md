## Premises found false (9)

- 'Modelled on the transactions export' would copy two defects. (1) The read cell is decided on the COOKIE role: mayReveal(session.role, …) at transactions route.ts:148, while its own gate re-reads the stored role at :88-89. A demoted officer holding an old cookie keeps full numbers. test:read-tiers 8.9 even pins the `mayReveal\(session\.role` regex (read-tiers.test.mts:609). <Sensitive> and the U20 loader both use the STORED role (sensitive.tsx:45-49, contacts-loader.ts:39-44), so U34 must use u.role. (2) The filter goes into the unprunable audit chain raw, including `q` (:169). For contacts, a whole-number search is a phone number in an audit payload, which §5.14 forbids. Both are recorded here, not fixed: the transactions route is outside §6's permission list.
- 'the ' formula guard that the importer's unguard reverses': no `unguard` exists anywhere in src/ or scripts/ (grep). The transactions guard cannot be reversed: guard("'=x") is "'=x" (it starts with ', so no prefix), and any unguard turns that into "=x". A guard that reverses exactly must prefix ' whenever the string matches /^'*[=+\-@\t\r]/. Unguard then strips exactly one ' when the string matches /^'+[=+\-@\t\r]/.
- 'a UTF-8 BOM written and stripped as a PAIR', as part of the model: the transactions export writes NO BOM (route.ts:177, the body starts at the header). The BOM writer is new in U34, and the stripper (U25) is unbuilt.
- 'Travels as the FILTER through contactAudience': contactAudience does not exist yet. src/lib/server/marketing/ holds consent-ledger, consent, dispatch, dsar, erase, ledger-stamp, optout-service and rg, with no audience.ts. U24 builds it at S11. The store's only reads are offset-paged page() (prisma-dal.ts:3624, skip/take) and fetch-all listAll(). §3c rule 5 forbids both for a 150k export, so U34 needs a keyset walk.
- 'answering 404 (don't confirm the endpoint)' is only half true. Next 16 (package.json:1035) renders src/app/not-found.tsx as HTML for an unrouted /api path. A route answering text/plain 'Not Found' can therefore be told apart by its body. The transactions route has the same tell. The protection is that nothing is served, not that the path is secret.
- 'Accept: export → re-import returns 0 invalid and 0 changed' holds only for the FULL file. A masked file's number '+255••••01' parses to digits '25501', so parseTzNumber returns too_short and every row is invalid. GROWTH, the role that runs campaigns, can never round-trip, by design (OD25). Also, '0 changed' passes trivially under the importer's default 'keep what's in the book', where every row counts as skipped. It means something only under 'take the file's version' and 'fill blanks only' (U31).
- The plan's BOM red ('the first header mangles') can be blind. JavaScript's String.prototype.trim() removes U+FEFF, so if U28's header matcher trims, an unstripped BOM silently disappears. The red stays sensitive only because the header cells are ALWAYS QUOTED: a leading U+FEFF breaks the opening quote, the first field reads `\uFEFF"phone_e164"` with the quotes included, and trim does not rescue it. So an assertion must pin that the header cells are quoted.
- U23's text includes 'export' among the bulk actions needing a typed word above 50 or when the audience is a filter, enforced on the server. That is incompatible with a GET download link. Decided on delegation: an export writes nothing to the book, so it needs no typed confirmation. U23's typed word governs writes only. U23's designer must drop export from that rule.
- test:read-tiers, U19's own guard, is NOT in `predeploy` (package.json:300 lists test:contacts-page, test:rbac and test:admin-nav, but not test:read-tiers or test:erasure). It gates no deploy. U34's masking must be asserted inside the new suite, which must itself join predeploy.

### What each file does

**1. `src/lib/csv-cell.ts`** (create)

THE ONE CSV WRITER (U34 now, U48 later). Pure and imports nothing. Exports CSV_BOM = String.fromCharCode(0xfeff), guardCell, unguardCell, csvCell (always double-quoted, '"' doubled, guarded), csvLine (cells joined by ',' and ending CRLF) and stripBom (removes exactly ONE leading U+FEFF). guardCell prefixes ' when /^'*[=+\-@\t\r]/ matches; unguardCell strips one ' when /^'+[=+\-@\t\r]/ matches, so unguardCell(guardCell(s)) === s for every s. The header comment explains why the transactions cell() does not reverse exactly.

**2. `src/lib/contacts/contact-labels.ts`** (create)

**3. `src/lib/contacts/redact-phone.ts`** (create)

## Risks (17)

- Two defects of the transactions precedent must NOT be copied, and they stay live there, outside §6's permission: mayReveal(session.role) (route.ts:148, pinned by read-tiers 8.9 at read-tiers.test.mts:609) and a raw `q` in an unprunable audit payload (:169). - The live proof cannot work by comparing before and after. A signed-out GET is 404 both before the deploy (no route) and after it (refused by design), and production has no QA staff login (only Ali's, never used; U17/U19 precedent). Proof is the deploy SHA by ?dpl= plus the local drive and execution. ✅ still owes one staff-session download on www.50pick.tz.
- Prisma's `{ not: 'erasure' }` excludes NULL rows while the memory twin's !== keeps them, so the twins disagree and only Postgres shows it. Mitigation: the OR[{sourceRef:null}, {not}] arm, a source assertion (K6) and one embedded-Postgres run.
- The id keyset relies on Postgres' en_US collation applying to both `id > cursor` and ORDER BY, which is self-consistent. The memory twin must use ONE code-unit comparator for both, never localeCompare for sort and > for the cursor (the ledger-stamp lesson). Exactly-once is asserted on ids that differ in case and punctuation.
- Streaming changes when the audit can be exact. Both audit rows are written before the first byte with the COUNTED total, and the generator stops at that count (K3), so pii.revealed can only over-state, never under-state. A row that starts matching mid-walk may displace a counted one; contacts.exported still carries the counted number. Recorded as the accepted direction of error.
- The masked file can never round-trip (OD25 by design). GROWTH, the campaign role, must ask an officer with `read` for a re-importable file. If U28/U30 do not recognise 'phone_masked', a masked re-import shows thousands of 'invalid' rows instead of one named refusal (M4).
- The BOM red is only as sensitive as the header quoting. JS trim() strips U+FEFF, so if anyone later 'simplifies' header cells to unquoted, a missing stripBom would pass silently. C2 pins the quoting for that reason.
- Write/Edit tools decode '\uFEFF' into a raw invisible character (memory: reference_edit_tool_decodes_escapes). Use String.fromCharCode(0xfeff) (precedent ai-poll-generation.ts:419); C4 scans for a raw U+FEFF.
- Excel and the leading apostrophe: some spreadsheet apps show the ' literally when opening a CSV rather than treating it as a text prefix. This is not measured here; open both files once in Excel, LibreOffice and Google Sheets during the drive and record what each shows. - U23 conflict: its text puts export under the typed-word confirmation enforced on the server, which a GET link cannot carry. Decided on delegation that export, which writes nothing, needs none. U23's designer must be told, or U23 will build a server refusal that breaks this link.
- URL length: a ticked-row selection expressed as ids= in a GET is capped (≈200 ids, ~5 KB, under Cloudflare/Node header limits). Larger selections must be expressed as the filter (U23).
- test:read-tiers is not in predeploy (package.json:300), so U19's masking guard gates no deploy. If test:contacts-export were not added to predeploy in the same commit, the export's masking would also gate nothing.
- Automatic probes: platform-pii-probe.mts:268 and house-bot-console-probe.mts:549 walk src/app/api/admin and will hit the new route with a forged viewer or a COMPLIANCE officer. Both should get 404 (COMPLIANCE has no growth view). Run them once in the serial battery. test:house-bot-surfaces 1.words.1 scans the route's literals, so no house-feature words there.

Railway's whole-request ceiling for a long stream is not measured; measure once on production with Ali's export, or record it as unmeasured.
