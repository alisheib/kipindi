### Assertions (24)

- P1 FIXTURE CONTROL — the 40-record fixture yields ≥1 row in EACH of the six buckets. Without it, a dropped increment on an empty bucket cannot change the sum and R1 would pass silently.
- P2 — the 40-record fixture's counts deep-equal the hand-computed expectation and sum to rowsRead=40. Fails if any bucket is missing or mis-classified.
- P3 — assertPreflightAdds throws PreflightArithmeticError on sum=rowsRead−1, sum=rowsRead+1, a negative count and a non-integer, and does NOT throw on the exact sum (positive control). Fails if the export is missing or is a no-op.
- P4 — with any ONE bucket's increment dropped (six in-process plants), computePreflight throws PreflightArithmeticError. The red harness checks the error class, so it failed for the right reason.
